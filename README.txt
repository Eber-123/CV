PORTAFOLIO PROFESIONAL - EBER PAUCCARA HUANCARA

Estructura:
- index.html: contenido y secciones de la web.
- css/styles.css: estilos, diseño adaptable, colores y efectos interactivos.
- js/script.js: menú móvil, animaciones de entrada y lógica del QR.
- assets/img/: fotografías e identidad visual.
- assets/certificados/: imágenes de certificados.
- assets/documentos/: CV en PDF y archivo Word oficial original.

ABRIR EN VISUAL STUDIO CODE
1. Descomprime el ZIP.
2. Abre la carpeta portafolio-eber en Visual Studio Code.
3. Instala la extensión Live Server.
4. Haz clic derecho en index.html y elige Open with Live Server.

CV OFICIAL
El archivo CV-Eber-Pauccara-Huancara-Oficial.docx es una copia exacta del documento que entregó el usuario; no se modificó ni se remaquetó. La web descarga directamente este archivo original para preservar su contenido y formato de origen.

QR
El QR mostrado es referencial y no escaneable hasta publicar el PDF en una URL pública. En js/script.js, reemplaza PUBLIC_CV_URL por la dirección HTTPS pública del archivo DOCX. La librería QRCode se carga desde CDN.

PUBLICACIÓN
Sube toda la carpeta a un servicio de hosting estático (por ejemplo, GitHub Pages, Netlify o similar). Mantén la estructura de carpetas para que funcionen las rutas.
